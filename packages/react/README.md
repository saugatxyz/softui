# @soft-ui/react

Soft UI React components.

## Install

```bash
npm i @soft-ui/react @soft-ui/tokens @soft-ui/icons
```

## Required Styles

Import once at app root:

```ts
import "@soft-ui/tokens/styles.css"
```

## Tailwind v4 Source Scanning

Add package sources in your global CSS:

```css
@source "../node_modules/@soft-ui/react/dist/**/*.{js,mjs}";
```

## Import Components

```tsx
import { Button } from "@soft-ui/react/button"
```
