# Fresh Dev Server

Kill all processes on ports 3000-3005 and start a fresh dev server.

## Instructions

1. Kill any processes running on ports 3000, 3001, 3002, 3003, 3004, and 3005
2. Wait 1 second for ports to be released
3. Start the dev server with `pnpm dev`
4. Run the server in the background so the conversation can continue

Use the script at `./scripts/dev.sh` or run the equivalent commands directly.
